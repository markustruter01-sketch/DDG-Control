2. Create lib/db/src/schema/tasks.ts and export it from lib/db/src/schema/index.ts. It defines two tables.

   members:
   - id: serial primary key
   - name: text, not null, unique
   - kind: text, not null, checked against MEMBER_KINDS (import it, same pattern as the projects status check)
   - created_at: timestamp, default now

   tasks:
   - id: serial primary key
   - project_id: integer, not null, references projects.id
   - title: text, not null
   - notes: text, may be null
   - status: text, not null, default "planned", checked against TASK_STATUSES (import it)
   - owner_id: integer, not null, references members.id
   - due_date: date, may be null
   - completed_at: timestamp, may be null
   - created_at: timestamp, default now
   - updated_at: timestamp, default now
   Add no other columns.
